What changes, screen by screen

0 · Foundation

Link tokens + components, fonts, map variables, swap button classes.

1 · Landing

Blurred table backdrop, name shuffle, room rows keyed by code, limit note, empty state, invited mode, shake.

2 · Header

Seat pills with group dots, your-turn ring + pulse, their-turn ring, offline hold ring, reserved score.

3 · Table

New colours and gradients, sights, ball LOD, tapered cue above balls, aim styles, effects list.

4 · Panels

Fixed-height slot, call line + Safety toggle, angle nudges, DOM spin pad, dismissible hint.

5 · Power bar

Ramp fill, readout, cancel zone, flash, needs-a-call tip, left-handed, keyboard.

6 · Dialogs

Option buttons with consequences, waiting banner, result banner, status tones, toast stack.

7 · Connectivity

Honest retry steps, taken-over variant, delayed splash, opponent hold countdown.

8 · Phone

Portrait stack, short-screen collapse order, landscape sidebar, touch rules, first-run hints.

The full checklist with one box per change is design/MIGRATION.md. The “Mockup only” block at the end of components.css (is-hover, is-focus, touch markers, callouts) is for this canvas and is not shipped.
